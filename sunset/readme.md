# @askviraj/ai-plugins

This package has moved to `@virajp.dev/claude-plugins`, developed at
<https://github.com/virajp/claude-plugins>. Use the new package for installs and
everything else:

```sh
pnpx @virajp.dev/claude-plugins --all      # install the plugins
pnpx @virajp.dev/claude-plugins --help     # everything else
```

Running this package only prints that pointer to stderr and exits with status 1.
It installs nothing and will not be updated again.
