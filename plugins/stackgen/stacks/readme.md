# Packs

Empty **by design, for now**. Packs — the dispatch rule's preferred,
pre-created path — arrive here in the merge waves, one wave at a time, in the
shape `../assets/pack-format.md` defines (`<axis>/<slug>/pack.yaml` + prose +
optional skills/agents).

Until then the curated plugins remain the covered-stack path, the menu skill
returns `templates: []` with its note, and stackgen's value is the uncovered
tail: `generated/<technology-slug>`.
